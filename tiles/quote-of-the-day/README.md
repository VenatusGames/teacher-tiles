# Quote of the Day

Literacy tile with 20 sourced public-domain quotations, author and book credits, source links, and original classroom discussion prompts. The collection rotates by local calendar day and works offline. Another previews a different quotation for the current day. Quotes and credits live together in quotes.js; source URLs point to the original works. Alcott’s quotations are character dialogue in Little Women.

The shared double-click heading editor and board serializer preserve custom titles and same-day selections.

Run `node tiles/shared/classroom-tests.cjs` for shared regression checks.
