# Vocabulary

Literacy tile with up to 80 hanging word cards. Add a word and optional definition, select a card to edit, or use its × button to delete. The gear menu controls card size and definition visibility. Words are entered directly for the current classroom; this tile does not alter saved student rosters.

Card text is rendered with textContent, bounded on entry and restore, and saved using the board special-state hooks. The shared heading editor, palette, fonts, and settings menu are used.

Run `node tiles/shared/classroom-tests.cjs` for shared regression checks.
