# Times Tables

Math tile with selectable fact families 0–12 and a multiplier range from 0 through 20. The gear menu chooses families and limits. Hide answers enables practice; select individual facts to reveal them or use Reveal all. Families, bounds, practice mode, revealed facts, and the shared editable heading persist with the board. Content scrolls within the tile.

Run `node tiles/shared/classroom-tests.cjs` for shared regression checks.
