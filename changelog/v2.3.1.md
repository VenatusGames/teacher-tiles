# TeacherTiles v2.3.1

## TeacherTiles 2.3.1 Content & Fixes Patch 
This is a small content & fixes patch based on feedback and bugs discovered in our first Live Demo today! Thanks for joining us! 

## New Features
- **Planner Improvements** - We've made some other improvements to the planner! Check them out!
- **Printable Lesson Plans** - Print your lesson plans out by day or week or save them as a PDF.
- **Calendar for Lesson Plans** - Block-out non-teaching days and holidays from your planner.
- **Day Schedule** - Set up a Day Schedule for your Planner based on the days in your Unit week.
- **Rich Text in Planner** - More text formatting options in the Planner.

## Changes
- Improved News feed functionality
- Improved Tile Fullscreen mode for a lot of tiles!
- You can now print Seating Chart Tile creations!
- Announcements now show the full text rather than needing a button to view.
- Added clearer visuals for when the minimum tile size has been reached.
- Times Tables Tile got some new features and improvements.

## Bug Fixes 
- Fixed bug with text scaling
- Fixed issues with frames not saving right and Board borders moving/camera shifting
