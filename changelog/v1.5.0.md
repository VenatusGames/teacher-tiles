# TeacherTiles v1.5.0 - The PBIS Update

### The PBIS Update
**MAJOR CONTENT UPDATE**
This update focuses on different PBIS and student incentive tools! Reward students with in-app tools or print our real-world incentives with in-app tools. This is the first-wave of PBIS related tools. There are more coming in future updates. Pick and choose what PBIS tools you like to use. Future updates will allow coordination across large organizations and groups.

## New Tiles
- Star Chart Tile - Class-Wide or individual student PBIS tool. Award students with stars. 
- Class Meter Tile - Fill a meter with your class to earn a Meter Fill Point!
- Student Race Tile - Horse-race style student PBIS game

- Prize Board Tile - Create various incentives and download PNGs you can send home digitally or print into physical coupons.
- PBIS Console Tile - A quick way to add or remove points for all PBIS tiles for students or whole class.

- Class Vs Class Tile - Laid Framework. Functionality coming soon

## New Features
- Student View Tool - View student's profiles from all your classese in the Student View Tool. Quickly see their tracked PBIS stats!
- Search individual students in Student View and review their stats
- Enable/Disable tracked stats in Student View! Choose the PBIS tools you like to use and disable the ones you don't!
- There is a badge on all tools that track PBIS stats
- Framework for Organizations feature
- Framework for notifications in profile

## Changes
- Completely remade Collections Jar to work with new PBIS system! Earn a jar fill for your class by filling the jar! 
- Can now download photos from Photobooth
- Moved delete class button in Manage Classes to a smarter spot
- Class Tool is now called Manage Classes Tool

## Bug Fixes 
- Fixed names not being able to be removed back to unassigned in tiles that take names
- Science Category holds Weather Wheel
