# TeacherTiles v1.4.0  - Tons of Tiles Update

### Tons of Tiles Update
**MAJOR CONTENT UPDATE**
This update adds a lot of new Tiles. This is a major content update. There was also some additional behind the scenes prep for the next major update... the PBIS Update!

## New Tiles
- Translate Tile - translate text or speak to translate
- Live Caption Tile - caption speech in real time
- Voice Memo Tile - record voice memos and play them back
- World Map Tile - explore the world
- Compass Tile - learn about a compass and how it works
- Mirror Tile - see & test your webcam
- Photobooth Tile - take pictures & apply filters
- Weather Tile - shows current weather for your location
- Weather Wheel - spin the weather to the current weather
- Season Wheel - spin the season wheel to the current season
- Temperature Tile - shows current temperature in thermometer form or number form
- Thermometer Tile - shows temp in different styles

## New Features
- New Science, Planning, Language, Geography, Accessibility, & PBIS categories 
- Image Tile Border system
- Added Zoom indicator on UI when zooming
- Search by category - type category into search bar
- Rename Tile Headings to fit your needs
- App Language support for 21 other languages added (Work in Progress)
- Weather Sticker Pack

## Changes
- Redesigned categories in Add Tile menu
- Hold shift while scrolling to do smaller scroll increments 

## Bug Fixes 
- Sub-menu title updates properly in help menu
- Fixed issues with text fields and double-click edit clashing with drag
- Fixed zoom increments
