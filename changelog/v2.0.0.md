## TeacherTiles Public Beta Launch Version
TeacherTiles has officially launched in Beta to the public! Share us with your friends! 
Paid Features are now live! This update also adds basic support for Organizations, Lesson Planning & lots of new content. Many bugs were also fixed and features were improved.

## New Tiles
- Magnifier Tile - It works like a magnifying glass. For accessiblity or exploring images when learning
- Pattern Maker Tile - Tool for building patterns with kids.
- Shape Manipulatives Tile - Tool for building with shape manipulatives
- Lesson Planner Tile - View your lesson plans created in the Lesson Planning Tool for the day or week
- Table Maker Tile - Create charts, graphs and more
- Tally Chart Tile - Realtime tally charts
- Attendance Tile - Attendance check in tool (Has cute Tile Skins in the shop!)
- Number Flashcards Tile - Number flashcards! 1-10, 1-25, & 1-100

## New Features
- Support us by subscribing! Unlock lots of perks with more on the way! 
- Purchase Themes, Stickers, Skins, Cursors and other cosmetics to support TeacherTiles remaining free and online!
- More Stickers
- Shop Improvements
- Lesson Planning Tool added
