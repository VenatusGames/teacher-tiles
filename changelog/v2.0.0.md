# TeacherTiles v2.0.0 - Public Beta Launch Version!

![TeacherTiles Screenshot](https://i.imgur.com/tssxcC7.jpeg)
## TeacherTiles Public Beta Launch Version
TeacherTiles has officially launched in Beta to the public! Share us with your friends! 
Paid Features are now live! This update also adds basic support for Organizations, Lesson Planning & **lots of new content**. Many bugs were also fixed and features were improved. The entire app has recieved a visual and clarity overhaul. This is our largest update to date.

## New Tiles
- Magnifier Tile - It works like a magnifying glass. For accessiblity or exploring images when learning
- Pattern Maker Tile - Tool for building patterns with kids.
- Shape Manipulatives Tile - Tool for building with shape manipulatives
- Lesson Planner Tile - View your lesson plans created in the Lesson Planning Tool for the day or week
- Table Maker Tile - Create charts, graphs and more
- Tally Chart Tile - Realtime tally charts
- Word Web Tile - Create a word web diagram visual and add words or blurbs of text 
- Venn Diagram Tile - Create Venn Diagrams
- Word of the Day Tile - Daily word and definition 
- Quote of the Day Tile - Daily positive vibes quote 
- Attendance Tile - Attendance check in tool (Has cute Tile Skins in the shop!)
- Number Flashcards Tile - Number flashcards! 1-10, 1-25, & 1-100
- Image Search Tile - Search images and drag them onto the board
- Minesweeper Tile - play Minesweeper
- Dice Tile - roll a six-sided die
- Seating Chart Tile - plan your classroom seating arrangements
- Fish Tank Tile - Noise Detection/Classroom Management! Keep quiet and gather more fish! 
- Sleepy Monster Tile - Noise detection/Classroom management tile. Features a very sleepy monster and noise will wake him up! 
- Butterfly Garden Tile - Noise Detection/Classroom Management! Grow a garden and attract butterflies by being quiet! 
- Quiet Critters Tile - Noise Detection/Classroom Management! Be Quiet and collect Quiet Critters! 
- Vocabulary Tile - Display your vocab words
- Times Tables Tile - Displays multiplication fact families 
- Google Search Tile - In App Google Search
- Link Tile - Set an image and link to an out-of-app service
- Background Remover Tile - Remove image backgrounds in-app
