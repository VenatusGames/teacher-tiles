# TeacherTiles v1.3.0

Google Integration & Board Saving

- This is a basic integration of saving & loading + accounts. A better version is coming soon. As we roll this feature out for testing, you may expierience issues with saving and loading. The app currently uses a free hosting plan while our userbase is small. If the quota for this plan is hit, your progress may not save until the next day rolls over. When we officially launch the app, this will no longer be an issue! 💙

## New Features
- Sign-In with Google to save your boards and layouts.
- Create multiple different boards
- Access your profile

- Shift-Left click is now tied to the group select tool

- Fixed shop button cursor change
- Contact email rerouted to teachertiles@gmail.com
