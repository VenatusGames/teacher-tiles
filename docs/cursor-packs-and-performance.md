# Cursor packs and board rendering — September 2026

The frontend adds these coin products (all five colors included):

| Product ID | Name | Coins |
| --- | --- | --- |
| `cursor-pixel-pack` | Pixel Cursors | 350 |
| `cursor-soft-pack` | Soft Cursors | 350 |
| `cursor-fluid-pack` | Fluid Cursors | 400 |

The external Firebase `purchaseCosmetic` backend must register these IDs and prices, and include them in subscriber cosmetic access. Its source is not in this repository. Client listings and entitlement checks are implemented; production purchases cannot be verified here. Do not bypass server coin validation.

Cursor PNGs and catalog metadata are generated by `scripts/generate-cursor-packs.cjs` (Sharp required). Board material WebPs and `assets/themes/baked.css` are generated by `scripts/bake-board-themes.cjs`. Keep the original SVGs as editable sources. Twenty-four baked textures total approximately 2.4 MB; only the active board texture is requested. Animated Underwater and Rainy Window remain animated.

All live membership icons reference `assets/ui/subscriber-crown.svg#crown`. The standalone subscription banner embeds the identical paths because SVG image resources cannot load external SVG references; keep these in sync when changing the crown.

Performance fixes remove the perpetual tab-strip layout loop and redundant digital clock formatting/layout. The tab-strip benchmark with thirty tabbed tiles went from 28,860 bounding-rectangle reads over two seconds to zero while idle. A second run using thirty tabbed clocks recorded 5,376 layout reads and 16 frames over 32 ms before the fixes, versus zero reads and zero frames over 32 ms afterward in a two-second sample. Run with `PERF_BASELINE=1` to route the original committed app/tab code for comparison. This isolates the layout improvement; it is not a guarantee of frame rate on every device or with thirty active video/canvas tiles.

Browser checks: `scripts/cursor-flashcard-coin.test.cjs` and `scripts/large-board-performance.test.cjs` (Playwright / Edge). The former covers every flashcard type, back/forward state persistence, Coin Flip, all cursor variants, and baked board image loading.
