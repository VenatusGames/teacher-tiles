# TeacherTiles v2.3.0 - Fall into Thanksgiving!

![TeacherTiles Screenshot](https://i.imgur.com/ESgbtUr.jpeg)
## TeacherTiles 2.3 Update - Fall into Thanksgiving!
The Thanksgiving Event is now live and Thanksgiving Tiles have been added to the app! Various Fall & Thanksgiving cosmetics are now available in the shop! This is our Fall/Thanksgiving update! We have also made some other improvements to the app and added some other features and new content!

## New Tiles
- **Thanksgiving Timer Tile** - New Thanksgiving Pie themed visual timers!
- **Thankful Turkey Tile** - What are you thankful for? Create a thankful turkey!
- **Cook-A-Feast Tile** - A Thanksgiving-style progress meter!

## New Features
- **Thanksgiving & Fall Seasonal Cosmetics** - Check out new themes, cursors, and stickers to celebrate this time to be Thankful and the fall season! 
- **Improvements to Grade Level Filtering** - Tiles with custom grade-level settings default to the setting of the filter you have active if only one grade level filter is selected.
- **Student View & Manage Class Tool Changes** - These tools have been combined into one tool called "Class View". We've overhauled and streamlined the visuals and mechanics in prepration for the upcoming ClassConnect features and more student features that are coming soon. There are already some new Student View related features in this tool.
- **User Notifications** - TeacherTiles can now sent announcements and important update notifications directly to users in their profile notifications.


## Changes
- **Thanksgiving Bundles & Sales** - Keep your eyes on the store! Products may go on sale or bundle together for a better deal! 
- **Fall Splash Screen** - The Fall app load animation has been turned on! Disable in the settings!
- Visual improvements to Progress Bar Tile
- Theme Shelf Resdesign and Overhaul
- Organizations UI improved as we begin work on supporting larger district-wide features
- Moved collaborate button to Boards menu
- Lots of backend (and a little frontend) work on Organizations and District-Specific support 
- UI work and clarity/unification 
- Improvements to Sentence Expansion Tile
