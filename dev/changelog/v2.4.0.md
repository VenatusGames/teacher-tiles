## TeacherTiles 2.4 Update - ClassConnect & Holidays! 
It's here! Thanks for being so patient while we worked on this massive systems update. With this release comes lots of new content and features including the long awaited ClassConnect. Teachers can now create boards for their students to use via the Class View Tool or directly on the board with tiles. Establish a link for students via the ClassConnect button inside the class page and students can join a session whenever it is active or started. We will have more tutorials and clearer direction for ClassConnect in coming updates. This update introduces the core functionality! Please send us your feedback and ideas! We are excited to continue improving TeacherTiles for your use!

### **Please note: The ClassConnect features and related tiles are locked to subscription only for now. This is subject to change in the future but they need to be locked as we test and sort out costs. Thank you!**

Holiday content is also live in this update for Christmas and Hannukah! Explore new tiles and cosmetics!

- **Respond! Tile** - Students can answer a question created by the teacher.

## New Features
- **ClassConnect** - There is a lot to unpack here. We will have more streamlined tutorial videos coming soon. ClassConnect sessions can now be started from two main places. You can start a session directly from a ClassConnect tile or from a Class View Class's ClassConnect button (wow, what a mouthful!). Starting a session can allow guests to join via a temporary join code or you can sync up a class and if you have Student Access setup, more on that below, students can join directly from their access.
- **Student Access & Emoji PINs** - Students can now use a link created by their teacher to join a student access view. From this view, they can edit their student profile, view their PBIS, or enter a board session. They can also access any live ClassConnect tiles here too. Optionally, teachers can lock student profiles behind random Emoji PINs. Create a link for Student Access via the ClassConnect button inside of a Class in the Class View tool.
- **Board Sessions** - There are two types of board sessions -- *Controlled* and *Free*. A controlled session is controlled directly by the teacher. They decide what tiles students see at what times and what tools they can use. They can manipulate the student board or allow the student to simply watch the teacher's board. For a free session, the teacher can still set which tiles students can use, but students can pull up and delete these tiles at will. They are given more free access in order to use what they want when they want.
- **Presentation ClassConnect** - Interactive ClassConnect Tiles can now be used inside of presentations. When presenting, you can launch a ClassConnect session to allow students or an audience to join and watch the presentation on their devices. If interactive tiles are included, viewers or students can directly submit things or interact with the presentation in real-time. Only one presentation can be active in a session at a time, but you can quickly change presentations if you so choose to do so.
- **Session Templates** - COMING SOON. We will allow you to create your own pre-set session templates to quickly launch a specific set of tools to students or choose from some pre-made ones by us.
- **Session History** - COMING SOON. See the history of recent sessions including collected responses.
- **Holiday Cosmetics** - Lots of new holiday cosmetics.
