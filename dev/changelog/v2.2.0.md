# TeacherTiles v2.2.0 - Presenting Presentations! 

![TeacherTiles Screenshot](https://imgur.com/yADCfJF)
## TeacherTiles 2.2 Update - Presenting Presentations!
TeacherTiles is proud to present... Presentations! Our new presentation tool is live in it's early-beta form in app! Check it out now! Lots more improvements are coming to this tool in the coming updates. We hope we've created something that is easier to use and friendlier than other presentation apps! Soon, this tool will integrate with Class Connect features in a future update! We are so excited to share more soon! 

We've also added some tools for sorting the app by use-case or grade level. There are currently a lot of tiles catered more to K-2. As we expand to older grades and continue to explore things for younger students, we want to make sure there are ways to eliminate clutter from tiles you may never need or use. This is the first step in that direction!

This update also introduces Tile Effect cosmetics! Check them out!

## New Tiles
- **Presentation Tile:** Display and use your presentations directly on your board!

## New Features
- **Presentation Tool:** Create and edit presentations! Export them to use in other presentation-based apps. Present directly from TeacherTiles!
- **Use Tiles in Presentation:** Use some Tiles DIRECTLY in your presentation. More cross-compatibility coming soon! 
- **Import Presentations:** Import .pptx or .tt files and upload your outside presentations to the app!
- **Presentation Themes & Transitions:** Cosmetics to add flourish to your presentations! 
- **Grade Level Filters:** Overwhelmed by Tiles? Filter the app by Grade-Level! Do this directly from the Add Tile menu! Use-case coming soon!
- **Tile Effects:** A new type of cosmetic that can be equipped! It changes the finishing effect on various tiles!
- **New Cosmetics:** Many additional new cosmetics in the store!
- **Draw Tile Overhaul:** The Draw Tile has seen some significant changes and improvements!

## Changes
