# Word of the Day

Literacy tile with 80 original classroom definitions and examples in two 40-word collections. Uses the local calendar date, stays stable throughout the day, and automatically changes after midnight or when a hidden tab becomes visible. Another temporarily advances the selection; Today’s restores the daily word. Both collections work offline.

The editable heading, collection, and same-day selection persist in board state. Old-day selections reset to the current day.

Run `node tiles/shared/classroom-tests.cjs` for shared regression checks.
