# News implementation

- `feed.js`: loads and displays the in-app news feed
- `shared.js` / `styles.css`: shared article, photo and gallery rendering
- `document.js` / `document-model.js`: rich-text rendering and validation
- `portable.js` / `portable-model.js`: `.ttn` loading, export and validation
- `order.js`: shared article ordering

These are application source files. Put articles in `news/posts/` and images in `news/banners/`.
